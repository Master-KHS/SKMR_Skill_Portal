SKMR Skill Portal - Local Run
=============================

WINDOWS
  1) Unzip. You will see the 'out' folder and 'run.bat'.
  2) Double-click 'run.bat'.
  3) A black window opens, then your browser opens automatically.
     If not, type in browser:  http://localhost:8765/
  4) To stop: close the black window.

MAC
  1) Double-click 'run-mac.command'.
     If blocked: right-click -> Open -> Open.
  2) Browser opens at http://localhost:8765/

REQUIREMENTS
  - Python installed (you already have it from Streamlit). Node.js NOT needed.

FEATURES
  - Dashboard / Talent Search : works offline.
  - AI Talent Search : Gemini key is built in (gemini-2.5-flash),
    ask questions directly. Internet required for Gemini calls.
    After the demo, delete the key at https://aistudio.google.com/apikey
