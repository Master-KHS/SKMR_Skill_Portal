SKMR Skill Portal — 로컬 실행 방법
====================================

[Windows]
1. 이 압축을 풀면 'out' 폴더와 '시작.bat' 이 같이 있습니다.
2. '시작.bat' 더블클릭.
3. 검은 창이 뜨고, 잠시 후 브라우저가 자동으로 열립니다.
   (안 열리면 브라우저에 직접 입력: http://localhost:8765/ )
4. 종료: 검은 창에서 Ctrl+C, 또는 창을 닫으면 됩니다.

[Mac]
1. '시작-맥용.command' 더블클릭.
   - "확인되지 않은 개발자" 경고가 뜨면:
     우클릭 → 열기 → 열기 한 번만 눌러주면 됩니다.
2. 브라우저가 자동으로 열립니다. (http://localhost:8765/)

[필요 조건]
- Python 이 설치돼 있어야 합니다. (예전 Streamlit 쓰셨으면 이미 있음)
- Node.js 는 필요 없습니다.

[기능]
- 진단 결과 확인 / Talent Search : 바로 동작
- AI 인재 검색 : Gemini 키가 내장돼 있어 바로 질문 가능 (gemini-2.5-flash)
  * 인터넷 연결 필요 (Gemini 호출용)
  * 시연 후에는 보안을 위해 Google AI Studio에서 해당 키를 삭제하세요.
