[ SKILL 챗봇 참고 문서 폴더 ]

이 폴더에 문서를 넣으면 SKILL 챗봇이 질문에 답할 때 참고합니다.
(DB에 넣지 않고, 실행 중에 이 폴더의 파일을 직접 읽습니다.)

지원 형식:
  - 텍스트: .txt, .md
  - 표    : .csv, .xlsx, .xls   (예: 직무기술서, 발령이력)

사용 방법:
  1) 이 폴더에 문서 파일을 넣습니다. (컬럼/형식은 자유 — 그대로 읽습니다)
  2) 앱을 실행하고 우하단 SKILL 챗봇에 질문합니다.
  3) 챗봇이 폴더 문서 + 시스템 데이터(구성원/스킬/평가)를 근거로 답합니다.

표 파일 팁:
  - 첫 행을 헤더(컬럼명)로 두면, 챗봇이 "컬럼명: 값" 형태로 이해합니다.
  - 예) 직무이력.csv 헤더: 사번, 이름, 발령일자, 이전조직, 현조직, 직책, 직무명

주의:
  - 문서를 추가/수정한 뒤에는 챗봇에 다시 질문하면 최신 내용이 반영됩니다.
