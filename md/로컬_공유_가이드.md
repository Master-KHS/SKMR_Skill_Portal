# 로컬 공유 가이드

현재 앱은 `localhost:3000` 에서 실행됩니다.  
다른 사람에게 링크만 공유하려면 로컬 URL이 아니라 터널 URL이 필요합니다.

## 가장 빠른 방법

1. `web/run-server.bat` 실행
2. 앱이 `http://localhost:3000` 에서 열리는지 확인
3. `web/run-tunnel.bat` 실행
4. 출력되는 공개 URL 공유

## 주의

- 내 PC가 켜져 있어야 합니다.
- 앱 실행 창과 터널 실행 창을 둘 다 켜둬야 합니다.
- 링크는 임시 링크일 수 있습니다.

## 준비물

둘 중 하나만 설치하면 됩니다.

- `cloudflared`
- `ngrok`

설치 후 `web/run-tunnel.bat` 를 다시 실행하면 됩니다.
