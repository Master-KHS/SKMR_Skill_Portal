# SKMR Skill Portal — 사용가이드

Skill 기반 인재관리 프로토타입입니다. 권한(페르소나)을 바꿔가며 메뉴와 데이터가 어떻게 달라지는지 확인할 수 있습니다.

---

## 1. 실행 방법

### 클라우드 (어디서나, 설치 불필요)
**https://skmrskillapp.streamlit.app** 접속 — 끝

### 로컬 PC (내 컴퓨터에서)
- **최초 1회**: `scripts\setup.bat` 더블클릭 → 환경 자동 설치
- **매번 실행**: 바탕화면 **SKMR Skill Portal** 아이콘 더블클릭 → 브라우저 자동 열림
- **종료**: 검은 창에서 `Ctrl+C`

---

## 2. 페르소나 전환

사이드바 최상단 **2단 selectbox**로 권한과 인원을 바꿉니다.

| 1단: 권한 선택 | 2단: 사람 선택 |
|---|---|
| HR Admin / HR Viewer / Team Leader / Calibration 참여자 / Skill Committee 위원 / 경영진 / 구성원 | 해당 권한으로 매핑된 구성원 중 1명 |

→ 바꾸는 즉시 **사이드바 메뉴 + 화면 데이터 범위**가 전환됩니다.

## 4. 메뉴별 기능 설명

### Foundation

**운영 정책 관리**
- Family / Sub-family / Level 명칭·설명 편집
- Skill 체계 자체를 변경해야 할 때 사용 (HR Admin 전용)

**Skill Library**
- 134개 Skill 조회·검색·필터 (Family / Sub-family / 키워드)
- Skill 선택 시 우측에 정의 + Level Criteria 4단계 상세 표시
- Skill 추가·수정·삭제 (HR Admin만 편집 가능)

**구성원 Master Data**
- 정답 파일: `data/members.xlsx`
- 화면에서 표 직접 편집 가능 + 엑셀 업로드/다운로드
- `persona_role` 컬럼으로 각 인원의 권한이 결정됨

**Assessment 라인 관리**
- 각 구성원의 N+1(직속 팀장), N+2(담당) 평가자 자동 매핑 결과 확인
- 누락된 평가자 검색 및 수동 보정

**Admin 권한 관리**
- 시뮬레이션 140명 데이터 ON/OFF
- Critical Skill 지정 (전사 핵심 Skill 토글)
- 시드 데이터 개별 재적재
- DB 전체 리셋 (초기화)

---

### Assessment

**필요 Skill 정의**
- Required(필수) Skill 지정: 전사 공통 / 조직별 / 개인별 3단계
- Enabler 4개는 전사 Required 자동 포함
- Core Skill은 Required 중 핵심 5개 강제 지정

**자가 진단**
- 좌측: 본인의 Required Skill 목록
- 우측: 선택한 Skill의 진단 카드 (Level 선택 + Evidence 첨부)
- 타팀 Skill 풀 신청 기능 포함

**리더 진단**
- 팀원의 자가 진단 결과를 보고 리더 의견 입력
- Lv 1~2: 즉시 확정 → Skill Profile 자동 반영
- Lv 3 이상: Calibration 단계로 진입

**Calibration**
- 부서 내 팀원들의 리더 진단 결과 비교 (9개 지표 후보자 카드)
- Lv 3: 이 단계에서 확정
- Lv 4: Committee 후보로 넘김

**Narrative 작성**
- Lv 4 Committee 후보자의 의결 자료 작성
- 성과 근거 / 외부 검증 / 종합 의견 입력

**Committee**
- Lv 4 최종 의결
- Narrative 내용 확인 후 Final Level 확정
- 확정 즉시 Skill Profile 자동 반영

**최종 결과 확인**
- 본인 (또는 선택 인원)의 Skill Profile 종합
- Radar Chart (Sub-family별 평균 Level)
- 평가 진행 현황 매트릭스
- 과거 평가 History 조회

---

### Reporting

**진단 결과 확인 (Dashboard)**
- KPI 카드: 전체 구성원 수 / 진단 참여율 / Required 충족률 / Critical 보유율
- 조직별 필수 Skill 현황 카드 (팀별 충족률 %)
- 평가 단계별 진행 현황

**Talent Search**
- Family / Sub-family / Level / 팀 등 다중 조건 필터
- 특정 Skill 보유자 검색
- 인재 리스트 → 개인 Skill Profile 바로가기

## 5. 평가 워크플로 전체 흐름

```
1단계  자가 진단    구성원이 본인 Skill 자가 평가
          ↓
2단계  리더 진단    팀장이 팀원 결과 검토 + 의견 입력
          ↓
      Lv 1~2 ──────────────────────── 즉시 확정 → Skill Profile 반영
      Lv 3   ──→  3단계 Calibration → 확정 → Skill Profile 반영
      Lv 4   ──→  3단계 Calibration → 4단계 Narrative 작성 → 5단계 Committee → 확정
```

## 6. 시연 시나리오 (처음 보여줄 때 추천 순서)

1. **경영진 페르소나** → 진단 결과 확인 → 전사 KPI + 조직별 현황 브리핑
2. **HR Admin 페르소나** → Skill Library → 134개 체계 설명
3. **구성원 페르소나** → 자가 진단 → 진단 카드 작성 시연
4. **Team Leader 페르소나** → 리더 진단 → Lv 분기 설명
5. **Calibration 페르소나** → 후보자 비교 카드 (9개 지표)
6. **Committee 페르소나** → Narrative 확인 + 최종 의결
7. **최종 결과 확인** → Radar Chart + History

## 7. 구성원 마스터 편집

### 엑셀로 편집 (권장)
1. `data/members.xlsx` 열기
2. 수정·행 추가·삭제
3. 저장
4. 앱 → 구성원 Master Data → **엑셀 새로고침** 클릭

### 앱 화면에서 편집
- HR Admin 페르소나 → 구성원 Master Data
- 표 셀 직접 클릭하여 수정
- 하단 **변경사항 저장** 버튼

### 페르소나 매핑 값 (persona_role 컬럼)
| 값 | 권한 |
|---|---|
| hr_admin | HR Admin |
| hr_viewer | HR Viewer |
| team_leader | Team Leader |
| calibration | Calibration 참여자 |
| committee | Skill Committee 위원 |
| executive | 경영진 |
| employee | 구성원 |

## 8. 자주 묻는 질문

**Q. 화면이 깨지거나 빨간 에러가 떠요 (로컬)**
→ 검은 창에서 `Ctrl+C` → 바탕화면 아이콘 다시 더블클릭

**Q. 엑셀 수정 후 화면에 반영이 안 돼요**
→ 구성원 Master Data → **엑셀 새로고침** 버튼 클릭

**Q. 데이터 전부 초기화하고 싶어요**
→ Admin 권한 관리 → "DB 전체 리셋" → 체크박스 체크 → 실행
→ (members.xlsx는 보존됩니다)

**Q. 시뮬레이션 140명을 빼고 싶어요**
→ Admin 권한 관리 → 시뮬레이션 데이터 토글 OFF

**Q. 새 PC에서 로컬 실행하려면?**
→ GitHub(https://github.com/Master-KHS/SKMR_Skill_Portal)에서 코드 다운로드
→ `scripts\setup.bat` 실행 → `scripts\run.bat` 실행

**Q. 클라우드 버전에서 데이터가 초기화됐어요**
→ Streamlit Cloud는 서버 재시작 시 DB가 초기화됩니다 (시드 데이터로 복원)
→ 영구 데이터 보존이 필요하면 로컬 버전 사용 권장
