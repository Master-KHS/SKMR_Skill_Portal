# SKMR Skill Agent PRD

## 1. 제품 개요

제품명: `SKMR Skill Agent`

이 제품은 SKMR의 Skill 기반 인재관리 체계를 실제 운영 전에 시뮬레이션하고, 현재 보유한 구성원 정보와 Skill 진단 결과만으로도 인재 검색, 적재적소 배치, 육성 포인트 도출이 가능하도록 만드는 내부용 Agent다.

이 제품은 아래 두 가지를 하나의 경험으로 묶는다.

1. AI 인재검색
2. On-demand Skill Dashboard

## 2. 문제 정의

현재 핵심 문제는 단순한 운영 pain point가 아니라, Skill 진단 체계가 실제 제도화되기 전에 아래를 미리 검증해야 한다는 점이다.

- 어떤 데이터 구조로 운영해야 하는가
- 어떤 권한 체계로 돌아가야 하는가
- 자기진단, 리더진단, Calibration, Committee, 최종 Profile 흐름이 실제 화면과 저장 로직으로 어떻게 작동해야 하는가
- 현재 정보와 Skill 진단만으로도 어느 수준까지 인재 검색과 육성 인사이트가 가능한가

즉, 이 제품의 1차 목적은 `제도 도입 전 운영 흐름을 먼저 구현해보고 정착 시행착오를 줄이는 것`이다.

## 3. 목표

### 비즈니스 목표

- Skill 진단 시스템 도입 전 운영 구조를 사전 검증한다.
- 인재 검색, 배치, 육성 포인트 도출이 가능한 최소 운영체계를 구축한다.
- 향후 실제 제도 도입 시 재사용 가능한 UI, 데이터 구조, 권한 체계를 확보한다.

### 사용자 목표

- 필요한 Skill 조건으로 후보를 바로 찾는다.
- 특정 구성원의 Skill 현황과 강점을 바로 확인한다.
- 조직 기준으로 육성 우선 Skill을 빠르게 본다.
- 질문 1건에 대해 추천과 요약 대시보드를 동시에 본다.

## 4. 대상 사용자

- 팀장 / 조직 리더
- Calibration / Committee 역할 사용자
- Skill 진단 운영 담당자

## 6. 핵심 요구사항

### 6.1 검색/추천

- 자연어 질문으로 후보 검색이 가능해야 한다.
- 이름, 팀, 담당, 직종, 직책, R/L, Skill 키워드를 해석해야 한다.
- `주니어 = L4 이하`, `시니어 = L5 이상`을 실제 필터로 반영해야 한다.
- `씬필름 / thin film / 박막`을 Photo 계열 키워드로 확장해야 한다.
- 추천 시 경영진/경영 직군은 제외해야 한다.

### 6.2 개인 조회

- 특정 구성원 이름 질의 시 추천이 아니라 `구성원 Skill 요약`으로 답해야 한다.
- 보유 Skill 개수, 평균 Level, 상위 Skill, 전체 Skill 리스트를 보여줘야 한다.
- 평가 흐름, 발령 이력을 함께 보여줘야 한다.
- 개인 조회 메인 답변에는 KPI를 전면에 두지 않는다.

### 6.3 논문·학력 데이터 탭

- 개인 조회 시 별도 탭으로 제공해야 한다.
- 초기 구조는 아래를 포함해야 한다.
  - 학력 정보
  - 논문 메타데이터
  - 연구실 이력
  - 외부 검색 상태
- 외부 검색이 붙기 전에는 상태값으로 `pending` 또는 `needs_approval`을 명시해야 한다.

### 6.4 대시보드

- 질문 1건마다 후보 수, 평균 Level, KPI 근거 수, 팀별 평균 Level, 상위 후보를 요약해야 한다.
- 개인 조회에서는 Skill 요약 중심으로 재구성해야 한다.

## 8. UX 요구사항

- 메인 화면 오른쪽 하단에 플로팅 Agent 진입점 제공
- 클릭 시 패널 오픈
- 위치 드래그 가능
- 개인 조회 시 `Skill 요약` / `논문·학력 데이터` 탭 전환 가능
- 메인 답변은 간결해야 하며, 세부 정보는 탭이나 카드로 분리
- 전역 경고문은 최소화하고 후보/개인 단위로 근거를 나눠 보여줘야 한다.

## 9. 외부 연동 정책

- 외부 논문, Google Scholar, 연구실 이력 검색은 승인 후 실행
- 승인 전에는 구조와 상태만 준비
- 승인 후에는 아래 범위를 검색 대상으로 확장
  - 논문 메타데이터
  - Google Scholar
  - 연구실 / 랩 / 공개 연구 프로필

## 10. 성공 기준

- 현재 보유 정보만으로도 인재 검색이 가능하다.
- `씬필름 주니어 인력 추천` 같은 질문에서 임가영이 적절히 노출된다.
- 개인 조회에서 Skill과 학력/연구 정보가 분리되어 보인다.
- 메인 답변에 불필요한 전역 학술 경고가 사라진다.
- 향후 외부 연동을 붙일 자리가 이미 UI/응답 구조에 준비되어 있다.
